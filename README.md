# 📰 Fake News Detection using Machine Learning

## 📌 Overview
This project uses Machine Learning to classify news articles as Fake or Real using NLP techniques.

## 📊 Dataset
- Fake.csv
- True.csv
(Kaggle dataset)

## ⚙️ Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- NLP (TF-IDF)

## 🧠 Model Used
- Logistic Regression

## 🚀 Workflow
- Data preprocessing
- Text cleaning
- TF-IDF vectorization
- Model training
- Evaluation

## 📈 Results
The model achieves good accuracy in detecting fake news based on text content.

## ▶️ How to Run
1. Open notebook in Google Colab
2. Upload dataset
3. Run all cells

## 💡 Key Learning
Learned NLP pipeline and binary text classification using ML.
